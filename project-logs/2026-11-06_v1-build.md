## Work done

The house sequence was followed:

1. **Portability spike** (spec §14 step 1) — proven 3/3 in Chromium, Firefox and WebKit from `file://`.

3. **Plan, guide and workplan.**

5. **Build**, one story per commit.

## Key decisions (all in the design document's register)

- **No runtime third-party code.** The ZIP codec is our own, built on the browser's deflate.
- **A zero-dependency bundler.** Every inline script and style is admitted by SHA-256 hash under
  `default-src 'none'`, so nothing can reach the network.
- **The editor writes its own exact bytes into saved packages.** It embeds a JSON copy of itself
  and reassembles it, so a saved package always carries the editor that wrote it.
- **One sandboxed iframe** (`allow-scripts` only). The parent authenticates each message by window
  identity, channel, sequence number and per-scene token.
- **A single focus rule for every engine** (see the acceptance report's A07 note), because WebKit
  will not move focus into a new opaque-origin frame by script.

## Defects found by testing and fixed (each would have shipped otherwise)

- A `</script>` inside an embedded string ended the host script early (spike).
- Firefox includes the stroke in SVG bounding boxes, so tests now measure geometry through
  `getScreenCTM`.
- `String.replace` expands `$'` found in the bundle, so the self-copy uses a function replacement.
- Firefox lost focus on Close from inside the frame.
- WebKit scrolled the overflow-hidden viewport when a hotspot took focus.
- Edit gestures left keyboard focus in the last inspector field, so Delete and Ctrl+D went to the
  text box.
- `scripts/e2e.sh` passed its arguments unquoted, so a `|` became a shell pipe.
