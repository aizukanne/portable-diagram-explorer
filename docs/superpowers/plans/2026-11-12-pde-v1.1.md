# PDE v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. One story per commit.

**Goal:** Add an author-set running order of slides with full viewer navigation, SVG images, drill-downs that work inside hosted viewers such as SharePoint, and tolerance of re-zipped packages.

**Architecture:** The DOM-free core gains a schema version 2 and a `SlideCursor`, both Node-tested. The viewer shows slides in its existing root view. Drill-downs keep the sealed `srcdoc` frame, which is now given the host's nonce, and fall back to an in-page renderer when the frame cannot start. SVG is shown only through `<img>`. See the design document; this plan does not restate its reasons.

**Tech Stack:** ES2022, HTML, CSS, no runtime dependencies. Node 24 runs the build and unit tests (`node --test`). Playwright 1.64.1 runs in Docker through `scripts/e2e.sh`.

**Spec:** `docs/superpowers/specs/2026-11-12-pde-v1.1-design.md`, approved by the owner on 2026-11-12. Read it first. Section numbers below (§5.2 and so on) refer to it.

**Guide:** `design/pde-v1.1-guide/01-implementation-guide.md` · **Workplan:** `design/pde-v1.1-guide/02-workplan.md`

## Global Constraints

- No runtime third-party code (D1). No network access from any shipped document: hash-only CSP (D3), checked by the external-request listener in every e2e spec.
- Author text reaches the DOM only through `textContent`. `test/unit/nohtml.test.mjs` must stay green (D19).
- Core modules (`src/core/*`) stay DOM-free (D4).
- Every new rejection or alteration is an `Issue` built with `makeIssue(code, path, received, expected, why, fix, severity?)` from `src/core/schema.js`. It carries the received value quoted back, the accepted form as a runnable example, why it matters, and the code (house rule: no silent rejection, no silent alteration).
- `SCHEMA_VERSION = 2` and `PRESENTATION_FORMAT_VERSION = 2`. Readers accept 1 and 2.
- The app version becomes `0.2.0` in `package.json`, in Task 11 only.
- Browser tests run only through `scripts/e2e.sh`, never on the host, and never two at once (they share `./node_modules`).
- Running any single e2e file uses `scripts/e2e.sh test/e2e/<file>`. The full suite is `scripts/e2e.sh` with no arguments.
- Stage by explicit path only. Run `git show --stat HEAD` after every commit.
- Copy is fixed by the spec where quoted:
  - the notice text in §5.3;
  - the "Slide N of M" and "Slide N of M: <title>" announcements in A16 and A17;
  - "Last slide";
  - "Back to slide";
  - "Home".

## Review Focus

1. **Next or Previous pressed while a component menu, the history-limit dialog or a text field has focus.** Expected: nothing happens, and the key keeps its existing meaning. Tested in Task 4.
2. **Next pressed while drilled into a diagram that is itself a slide.** Expected: the sequence resumes from the *last slide shown on the page*, not from the drilled diagram (R3). Tested in Task 4.
3. **A file that only looks like an SVG.** An HTML document containing `<svg>` must stay `html`. An SVG preceded by a BOM, an XML declaration, a comment and a DOCTYPE must be recognised as `svg`. Tested in Task 7.
4. **A host nonce containing quotes or markup** (`a" onload="x`). Expected: it is ignored, and the frame starts exactly as on `file://`. Tested in Task 9.
5. **A Finder re-zip that has both a wrapping folder and AppleDouble entries** (`__MACOSX/name/._project.json`). Expected: it opens, and the warning lists every skipped name. Tested in Task 10.

## Task 2 (S2): SlideCursor

**Files:**
- Create: `src/core/slides.js`
- Test: `test/unit/slides.test.mjs`

**Interfaces:**
- Produces `class SlideCursor`, with:
  - `constructor(slides: string[], rootDiagramId: string)`
  - `get count(): number`
  - `get index(): number | null`
  - `get current(): string | null`, the diagram ID at `index`
  - `get hasNext(): boolean`
  - `get hasPrevious(): boolean`
  - `get isLast(): boolean`
  - `next(): string | null`, which moves and returns the new diagram ID, or `null` with no move
  - `previous(): string | null`
  - `jump(i: number): string | null`
  - `home(): void`, which sets `index` to the root's position or `null` (§5.8 item 8)
  - `label(): string`, which returns `"3 of 8"`, or `""` when `index` is `null`
- `index` starts at `slides.indexOf(rootDiagramId)`, or `null` when that is −1 (V4).
