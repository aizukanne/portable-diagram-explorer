# PDE v1 Implementation Plan

> **For agentic workers:** execute task by task; steps use `- [ ]` checkboxes. One story per commit.

**Goal:** Ship the spec's version 1: a self-contained offline editor, a self-contained presentation
export, an editable ZIP package, a three-level sample, schema, README and acceptance report.

**Architecture:** DOM-free ES modules for the core (Node-tested). Browser UI modules. A
zero-dependency bundler emits single-file HTML with hash-only CSP. One sandboxed srcdoc iframe is
driven by the parent shell over a validated, versioned postMessage protocol. See the design document
(Part 2) and the guide.

**Tech stack:** ES2022, HTML, CSS; Node 24 (build and unit tests, built-in runner); Playwright 1.64.1
in Docker (browser tests). No runtime dependencies.

**Conventions:** run commands from the repo root. "Confirm" steps check the toolchain versions:

```bash
node --version            # expect v24.x
docker image inspect mcr.microsoft.com/playwright:v1.64.1-noble >/dev/null && echo ok
```

```js
export function jsonForHtml(value) {
  return JSON.stringify(value)
    .replace(/</g, '\\u003c').replace(/>/g, '\\u003e').replace(/&/g, '\\u0026')
    .replace(/\u2028/g, '\\u2028').replace(/\u2029/g, '\\u2029');
}
```

- [ ] **Step 2: run.** It fails.
- [ ] **Step 3: implement.** These details are pinned:
  - names are UTF-8, with flag bit 11 set on write;
  - the DOS date is `0x0021` and the time is `0` (deterministic);
  - deflate is stored only if smaller;
  - the EOCD is found by scanning back at most 65,557 bytes;
  - the central directory's sizes are authoritative and must agree with the local header;
  - the decompressed length must equal the declared size, and the CRC must match;
  - a duplicate check is case-insensitive.
